# FEATURE_SPEC_001.md

## Funcionalidad
Crear pedido

## Descripción
El sistema debe permitir crear pedidos
de productos Apple.

---

# Criterios de aceptación

## AC-01
Todo pedido nuevo debe crearse
en estado PENDIENTE.

## AC-02
El nombre del producto no puede estar vacío.

## AC-03
El pedido debe persistirse correctamente.

## AC-04
El sistema debe generar un identificador único.

## AC-05
El pedido debe visualizarse en el tablero.
